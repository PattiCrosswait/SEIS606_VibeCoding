# Browser Acceptance Checks

Run these checks against the local Next.js application started with `npm run dev`.

- [ ] Keyboard-only users can reach navigation, sequence input, sample buttons, Analyze, and Download report.
- [ ] The current navigation item exposes an active/current-page state.
- [ ] Validation and completion messages are exposed through a live status region.
- [ ] The interface remains usable at narrow mobile and wide desktop widths.
- [ ] Long residue maps scroll intentionally rather than clipping the page.
- [ ] Download report creates a meaningful file containing the current analysis.
