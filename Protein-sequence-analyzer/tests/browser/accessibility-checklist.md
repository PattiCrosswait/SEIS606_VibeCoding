# Accessibility Checklist

- [x] All controls are reachable by Tab and activate with Enter or Space.
- [x] Focus remains visible on controls and navigation.
- [x] Inputs, buttons, tables, and status regions have accessible names.
- [x] Validation and async state changes use live status messaging.
- [x] Residue groups and result states are understandable without color.
- [x] Narrow layouts provide intentional scrolling instead of clipping.
